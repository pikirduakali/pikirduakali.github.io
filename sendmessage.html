How to — Articles

  1. Compose — Isi title, tag, date, hero image (opsional), dan body.
  2. Download .txt → articles/namafile.txt.
  3. Copy entry → Paste ke articles.json.
  4. Push — git add . && git commit -m "add artikel" && git push

How to — Projects

  1. Switch tab — Klik "Projects" di sidebar buat mode project.
  2. Compose — Isi title, category, hero image (opsional), dan body.
  3. Download .txt → projects/namafile.txt.
  4. Copy entry — Paste ke projects.json.
  5. Push — Sama kayak artikel.

How to — Site Content

  1. Switch ke Content tab — Klik "Content" di sidebar buat edit teks homepage.
  2. Edit — Semua teks dikelompokin per section (Hero, About, Services, dll). Tinggal klik & ubah aja.
  3. Copy full JSON — Klik "Copy full JSON" di toolbar, otomatis ke-clipboard seluruh site-content.json.
  4. Buka site-content.json — Paste isinya di file site-content.json.
  5. Push — git add . && git commit -m "update konten" && git push

How to Add Images

Supported in both Articles and Projects. Caranya:

  1. Upload gambar lo ke image hosting (ImgBB, imgur, Unsplash, atau GitHub issue attachment etc.), dapetin URL langsungnya.
  2. Hero image — Isi field "Thumbnail URL" di dashboard. URL itu otomatis kepake sebagai gambar hero di bagian atas halaman (tampil full-width, 16:9).
  3. Inline image — Di body editor, tulis di baris sendiri: img:https://namahosting.com/gambar-lo.jpg
  4. Contoh body dengan gambar inline: 
    Ini paragraf pertama.

img:https://i.ibb.co.com/gambar-saya.webp

Ini paragraf setelah gambar.
  5. Gambar inline — Akan tampil full-width dengan aspect ratio 16:9 di tengah konten. Bisa di artikel maupun project.
  6. Tips: Pake hosting gambar yang support hotlinking (ImgBB, imgur, Unsplash direct link). Hindari Google Drive atau shared drive karena biasanya gak muncul.

How to Delete

  1. Download .txt dulu — Klik entry yang mau dihapus, catet slug-nya.
  2. Hapus file — Hapus file articles/namafile.txt atau projects/namafile.txt.
  3. Hapus entry — Buka articles.json atau projects.json, hapus baris entry itu.
  4. Push — git add . && git commit -m "delete entry" && git push
Tips: Format entry JSON selalu pake double quotes ("). Kalo ada error pas di-push, cek lagi pastiin koma dan kutipnya bener.

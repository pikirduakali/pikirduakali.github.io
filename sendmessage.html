How to — Quick Publish (server mode)

  1. Start server — Klik 2x publish.bat di folder project.
  2. Compose — Isi title, body, dll di dashboard.
  3. Klik "Publish" (tombol hijau di toolbar) → file otomatis tersimpan + push ke GitHub.
  4. Selesai — Tunggu GitHub Pages deploy.

Dot hijau di toolbar = server nyala. Dot abu = server mati (pake cara manual di bawah).

How to — Articles (manual)

  1. Compose — Isi title, tag, date, hero image (opsional), dan body.
  2. Download .txt → articles/namafile.txt.
  3. Copy entry — Copy full articles.json (termasuk urutan & hidden state).
  4. Replace file — Timpa seluruh isi articles.json dengan hasil paste.
  5. Push — Klik gitpush.bat di folder project, isi pesan updatenya.

How to — Projects (manual)

  1. Switch tab — Klik "Projects" di sidebar buat mode project.
  2. Compose — Isi title, category, year, client, headline, hero image, dan body.
  3. Download .txt → projects/namafile.txt.
  4. Copy entry — Copy full projects.json (termasuk urutan & hidden state).
  5. Replace file — Timpa seluruh isi projects.json dengan hasil paste.
  6. Push — Klik gitpush.bat.

How to — Site Content

  1. Switch ke Content tab — Klik "Content" di sidebar buat edit teks homepage.
  2. Pilih section — Klik Hero / About / Services dll di sidebar kiri.
  3. Edit — Ubah teks di kolom yang tersedia.
  4. Simpan — Klik "Copy JSON" di toolbar → download file site-content.json.
  5. Replace file — Timpa file lama di folder project lo dengan yang baru didownload.
  6. Push — Klik gitpush.bat di folder project, isi pesan updatenya.

Text Modifiers — Site Content

Karena pake innerHTML, lo bisa pake HTML langsung di kolom Content biar teksnya lebih hidup:

Bold<strong>teks</strong>
Italic<em>teks</em>
~~Strikethrough~~<span style="text-decoration:line-through">teks</span>
Teks merah<span class="accent">teks</span>
Teks abu<span style="color:var(--muted-foreground)">teks</span>
Baris baru<br>
Teks kecil<small>teks</small>
UPPERCASE<span style="text-transform:uppercase">teks</span>
Font display<span style="font-family:var(--font-display)">teks</span>
Monospace<span style="font-family:monospace">teks</span>
Contoh implementasi di JSON: 
"hero-title": "Not trying to impress.<br><span class=\"accent\">Just trying to make it work.</span>"
"about-text-1": "9+ years in <strong>F&B operations</strong> and <em>digital creative</em> since <span class=\"accent\">2010</span>."
Catatan: HTML cuma jalan di field Content. Di body article/project (file .txt), HTML gak akan ke-render.

How to Add Images

Supported in both Articles and Projects. Caranya:

  1. Upload gambar lo ke image hosting (ImgBB, imgur, Unsplash, atau GitHub issue attachment etc.), dapetin URL langsungnya.
  2. Hero image — Isi field "Thumbnail URL" di dashboard. URL itu otomatis kepake sebagai gambar hero di bagian atas halaman (tampil full-width, 16:9).
  3. Inline image — Di body editor, tulis di baris sendiri: img:https://namahosting.com/gambar-lo.jpg
  4. Contoh body dengan gambar inline: 
    Ini paragraf pertama.

img:https://i.ibb.co.com/gambar-saya.webp

Ini paragraf setelah gambar.
  5. Gambar inline — Akan tampil full-width dengan aspect ratio 16:9 di tengah konten. Bisa di artikel maupun project.
  6. Tips: Pake hosting gambar yang support hotlinking (ImgBB, imgur, Unsplash direct link). Hindari Google Drive atau shared drive karena biasanya gak muncul.

How to Delete / Hide

  1. Pilih entry — Klik entry di sidebar.
  2. Klik ⋮ — Tombol opsi di sebelah kanan entry.
  3. Hide — Sembunyikan dari halaman publik (bisa di-unhide nanti).
  4. Delete — Hapus permanen dari array (konfirmasi dulu).
  5. Copy full JSON — Klik "Copy entry" di toolbar, paste & replace file .json.
  6. Push — Klik gitpush.bat.
